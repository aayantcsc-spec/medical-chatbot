Compare AI architectures

Ask one healthcare question in English, Hindi or Hinglish and compare the actual responses of the Rule-Based, Machine Learning (TF-IDF + SVM) and Deep Learning (DistilBERT) systems. Evaluate them on real datasets and collect participant feedback in one place.

Three approaches, one question

Every architecture receives the same original question and the same language preprocessing, and answers independently. No answer is ever substituted for another model's.

⌘

Rule-Based

Keyword and symptom rules over the curated knowledge base. Nothing is learned.

⌁

Machine Learning

TF-IDF features with a linear SVM classifier, trained on the intent dataset.

✳

Deep Learning

A fine-tuned DistilBERT classifier. It selects a topic; it does not write free text.

    What do these metrics mean?
    Lenient accuracy
    Question bank only: a prediction is correct if the expected category is any acceptable category of the predicted intent. On the exact-label datasets (held-out split, Hinglish + Hindi) there is only one acceptable label, so lenient and strict are identical.
    Strict accuracy
    Only the predicted intent's primary category counts as correct.
    Precision
    Of the answers a model gave for a class, the share that were right (macro average over classes present in the data). A "no confident match" is not a wrong class, so it does not lower precision.
    Recall
    Of the questions that truly belong to a class, the share the model found. A "no confident match" counts as a miss, so it lowers recall.
    F1-score
    The harmonic mean of precision and recall (macro average).
    Median and P95 latency
    Half of the answers were faster than the median; 95% were faster than P95. Measured per question inside the pipeline on this machine, so it depends on hardware and load.
    No-match count
    Questions where the model declined to pick a topic (below its confidence rule). These are kept in the denominator; they are not removed.
    Excluded questions
    Dataset rows removed for all models before running (empty, unknown label, duplicate, conflicting duplicate, overlap with training data). Model failures are different: they are counted per model.

    The question bank uses 19 coarse categories while the models predict 91 intents; they are compared through the author-defined mapping in datasets/evaluation_label_map.json, so reported question-bank scores depend on that mapping.
